# SetUp ZimaOS en Portatil viejo desmontado

Vamos a aprovechar un portatil viejo que tenia por cada para usarlo como dispositivo dentro del homelab instalando ZimaOS, pense en tambien unirlo al cluster e instalar proxmox pero debido a que ahora mismo no tengo huevo en mi switch y solo lo voy a poder conectar por wifi voy a optar por instalar ZimaOS.

## Requisitos

- Portatil viejo x86-64.
- USB 8gb.
- Disco externo HDD o SSD SATA con al menos 25 GB de almacenamiento.
- Balena Etcher.
