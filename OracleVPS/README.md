
# Set Up OracleVPS servidor cloud

## Objetivo

Usaremos este servidor cloud fuera de nuestra red local para servicios que queramos tener expuestos o otro tipo de cosas, actualmente lo uso como puerta para exponer mis servicios a través de un tunnel con Rathole.

## Requisitos

* Cuenta en Oracle Cloud Always Free
* Terminal Tmux para conectarte por SSH (Recomendado)
